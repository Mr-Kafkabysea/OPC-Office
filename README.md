# OPC Office

OPC Office is a live 3D dashboard for an AI team. Agents appear at desks on their department floors. The dashboard shows their status, current step, recent activity and reported usage.

## Open the dashboard

- [OPC Office](https://mr-kafkabysea.github.io/OPC-Office/) opens the dashboard directly. A browser with no connected channel sees demo data.
- To connect your own team, use the link generated by [PROMPT.md](PROMPT.md), or open your existing dashboard link once. The browser remembers the selected channel, so later visits to the root address load the same team. Old `/office/` links redirect to the root with their channel and settings intact.
- Add `?demo=1` to show the demo in the same browser. Open a different channel link to switch teams.

The channel is part of the private dashboard link. Keep it private because anyone who knows the topic can read and post to it. The dashboard supports ntfy and the [Cloudflare relay](relay/README.md).

## Development

The front end uses Three.js. Build the GitHub Pages files with Node.js 24:

```sh
node scripts/build-pages.mjs _site
```

Use an empty output directory. The Pages workflow builds and deploys the site on pushes to `main`.

For a local dashboard that reads a JSONL journal, see the [server guide](README-server.md). The [event contract](docs/CONTRACT.md) and [avatar guide](docs/AVATARS.md) describe the dashboard data.
